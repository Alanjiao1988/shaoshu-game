## 十改：本地化（v1.6.0）—— 图标 + Windows 桌面版

**用户提问**：「这是本地软件吗？能存档吗？」→「怎么能让他成为一个本地软件呢」

### 查证到的关键事实（决定了很多设计）
1. **Safari ITP 7 天规则**（WebKit 官方 blog/10218）：
   > 网站超过 7 天没有被交互，其 localStorage / IndexedDB / Service Worker 缓存会被全部删除。
   **但**：「添加到主屏幕的 Web 应用不属于 Safari，有自己的计时器，我们预期其第一方数据不会被删除；若被删属严重 bug。」
   → **结论：iPad 上必须用「添加到主屏幕」打开，不能用 Safari 书签。暑假两个月不打开就会丢数据。**
2. **主屏幕 App 的存储与 Safari 隔离**（by design，WebKit bug 181849）：
   → 先在 Safari 用过、再加到主屏幕 = 一个全新的空容器。**正确顺序：Safari 里先导出 json → 加主屏幕 → 在新 App 里导入。**
3. **Chrome 在 `file://` 下 localStorage 完全可用**（本轮实测：写入成功、刷新后读回成功、indexedDB/caches 都可用）。
   → 这条让"轻量桌面版"成立。

### 本轮交付
- **应用图标**（朱砂印章风，白字「主公」+ 小字「少年」）
  - 用无头 Chrome 渲染 SVG 截图生成，一次出 180/192/512/167 四个尺寸
  - `apple-touch-icon` 必须是**真实图片文件**（iOS 不支持 data URI）
  - manifest 从 data URI 改为真实的 `site/manifest.json`，这样才能带 icons
  - 本地单文件打开时 manifest 会 404 —— 无害，只是控制台一句警告
- **Windows 桌面版**
  - `启动少年主公.vbs`：双击 → Chrome `--app` 模式打开，独立窗口无地址栏
    - 自定位（用 `WScript.ScriptFullName` 推目录），整个文件夹可以随便挪
    - 数据落在旁边的 `少年主公_数据/`（专用 `--user-data-dir`），和日常浏览隔离
    - **必须存成 UTF-16LE + BOM**，WSH 读 .vbs 默认按 ANSI 解码，UTF-8 会乱码
  - `少年主公.ico`（256×256，手工拼的 PNG-内嵌 ICO）
  - 另给了"手动建快捷方式"的备用路径（因为 .vbs 可能被安全软件拦）
- **测试脚本改为常驻**：`.workbuddy/tests/logic.js` + `.workbuddy/tests/ui.js`，以后改完直接重跑，不用重写
  - 截图落在 `.workbuddy/tests/shots/`
- 版本 1.5.1 → **1.6.0**，schema 仍为 3

### 验证
- 逻辑测试 **71 项**，连跑 3 次全绿
- 浏览器测试 **20 项**（静态资源可取、manifest 内容正确、六视图渲染、SW 激活、图标进缓存），全绿

### 本轮踩坑
20. **`cscript`/`wscript`/`WScript.Shell` COM 都被沙箱安全策略拦了**（"Known Windows LOLBin"）。
    → 我无法在这里执行或验证任何 WSH 脚本，只能靠编码正确 + 逐行审读。已向用户说明并给了备用方案。
21. **写 .vbs 必须 UTF-16LE + BOM**，否则中文全乱码。
22. **手工拼 ICO 比走 System.Drawing 更可控**：ICO 头 6 字节 + 目录项 16 字节 + 直接内嵌 PNG。256×256 时宽高字节写 0。
23. 又一次 `getJSON` 拿到空响应导致 `JSON.parse` 炸 —— Node 侧做 CDP 客户端时，**空响应必须单独判掉**，不能直接 parse。

## 十二、适配华为平板（v1.6.1，未发布）

**用户问**：「华为的平板可以吗？」

### 查证结论
华为平板跑**鸿蒙**，跟 iPad 是两套规则，而且**比 iPad 宽松**：
- 华为浏览器有「添加至桌面」/「网页添加至桌面」（HarmonyOS NEXT 5.0.0.123 SP19 + 浏览器 5.0.8.300 起）：右下角「四个点」→「添加至」→「桌面」
- 符合 PWA 标准的站点（manifest + SW + HTTPS）会**自动识别并提示安装**，装完是独立窗口、无地址栏
- **图标必须能从 manifest 取到**，否则鸿蒙会回退成浏览器默认图标（我们 v1.6.0 起已达标）
- 安卓/鸿蒙**没有** Safari 那种 7 天清理规则，但磁盘紧张时 Chromium 可能回收"尽力而为"存储

### 本轮改动
1. **maskable 图标**：`icon-maskable-192.png` / `icon-maskable-512.png`。做法是把装饰内容 `transform="scale(0.72)"` 缩到中心 72%，背景仍铺满 —— 安卓/鸿蒙把图标裁成圆形时才不会切到字。manifest 里加两条 `purpose: "maskable"`
2. **申请持久化存储** `requestPersistentStorage()`：调 `navigator.storage.persist()`，让浏览器承诺不自动回收。设置页「数据管理」新增「数据保护」一行显示结果（granted/denied/unsupported/unknown），带「检查」按钮
3. `site/sw.js` 缓存清单补上 maskable 图标，版本 1.6.1
4. 图标生成器提取成 `.workbuddy/tools/makeicon.js`（以后换图标只改这一个文件）

### 验证
- 逻辑测试 75 项、浏览器测试 23 项，均全绿（浏览器测试连跑 3 次稳定）

## 十三、测试工具链的一次大排查（重要，以后别重踩）

浏览器测试突然从 23/23 变成 0/0，排查花了很久。**根因有三个，都记下来**：

### 坑 25：Chrome 会后台驻留，导致 profile 目录删不掉、进程越积越多
- 现象：每次跑完留一个 profile 目录（14~71MB），跑 3 次就 100MB，还有 29 个 chrome 进程存活
- `child.kill()` 只杀主进程；**`taskkill /T /F` 在本沙箱被拦**；**CDP 的 `Browser.close` 也不够**
- **真正的解**：启动参数加 `--disable-background-mode`（配合 `--disable-background-networking`）。加上之后 Chrome 正常退出，连跑 3 次零残留

### 坑 26：profile 不能用 `os.tmpdir()`
- 现象：Chrome 能建出 profile 目录、CDP 也能连上，但**永远 0 个 page target**，连 `Target.createTarget` 都无效
- 原因：沙箱里 Node 能读写系统临时目录，**Chrome 不行**
- 结论：profile 必须放在工作区内

### 坑 27：残留 Chrome 占着调试端口 → CDP 连到旧浏览器
- 现象：`找不到页面`，实际 targets 为空
- 这是老坑（第 3 条）的复发。**修法：启动前用 `net.createServer` 探测端口是否真空闲**，不要只靠随机数
- 同时给 `/json/list` 的循环包了 try/catch（CDP 刚起来偶发空响应，一次失败就中断整个测试）

### profile 的最终策略
唯一目录 + 跑前清扫上一轮遗留 + 跑完 `Browser.close` 并重试删除。
三个方案都试过：每次新建（会积压）、固定目录（和残留进程打架）、tmpdir（Chrome 用不了）—— 只有这个组合稳定。

### 新增工具（都在 .workbuddy/tools/）
- `makeicon.js`：生成含 maskable 的全部图标尺寸

### 测试脚本位置（常驻，别重写）
- `.workbuddy/tests/logic.js` — 逻辑测试 75 项，无浏览器
- `.workbuddy/tests/ui.js` — 浏览器测试 23 项，含截图（落到 `tests/shots/`）

### 关键设计取舍
1. **档位 = 实体卡等级**（武力轴），不是"稀有度轴"。理由：孩子手上有实体卡，**一致 > 我的判断**。孩子看到 App 里诸葛亮是良将不会困惑——他的卡上就写着 B-。
2. **图鉴按阵营分组**（汉/魏/蜀/吴），组内按等级从高到低 —— 和纸质核对表同构，好找。
3. **徽章显示等级字母**（SS~B-），未招募的卡也显示等级（作为线索，制造好奇）。
4. **抽卡权重重调**：`HERO_W {legend:10, rare:16, common:18}`，未获得加成 `2.2 → 3.5`（`HERO_NEW_BOOST`）
   - 实测分布：神将 4.9% / 名将 14.4% / 良将 58.6% / 锦囊 22%
5. **两套 class 名不能混**：卡片用 `t-common`，弹窗结果框用 `t-normal`。已抽出 `HERO_TIER_CLS` 和 `HERO_TIER_BOX` 两个映射。
